# TaskMaster

TaskMaster is a tiny command-line task manager written in Python. You add
tasks, give them optional due dates, and mark them done — all from the
terminal.

This site demonstrates the four kinds of documentation from the
[Diátaxis framework](https://diataxis.fr/):

- **Tutorial / getting started** — [Install](install.md) then the quickstart in the README.
- **How-to guides** — [Usage](usage.md).
- **Reference** — [API reference](api.md), generated from the docstrings.
- **Explanation** — [Architecture](architecture.md): why it is built this way.

New here? Start with [Install](install.md).
